# just-plug Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `just-plug` v1 — a single-file justfile module that installs, removes, updates, and verifies third-party justfile modules from GitHub, recorded in a plaintext manifest + lockfile.

**Architecture:** All public commands and private helpers live in a single `plug.just` file (the bootstrap downloads exactly this one file). Each public command is a bash recipe that orchestrates private `_`-prefixed helper recipes. Helpers are pure-ish where possible (parse, derive-name, gen-modules) and shell out to `git`/`curl`/`shasum` where I/O is needed. State lives in two whitespace-separated text files at the project root: `just-plug.deps` (user intent) and `just-plug.lock` (resolved state).

**Tech Stack:** `just` ≥ 1.14 (for `mod?`/`import?`), `bash`, `curl`, `git`, `shasum`, `awk`. Tests use a `tests/justfile` harness; integration tests spin up local bare git repos and a tiny HTTP server for fetch.

## Spec

The design spec is at `docs/superpowers/specs/2026-05-15-just-plug-design.md`. Refer to it for behavioral contracts when this plan is ambiguous.

## Path conventions (used throughout)

Inside `plug.just`, all paths derive from `justfile_directory()` which resolves to the **user's project root** (verified empirically: when a `mod?` brings in a module file, just variables still anchor to the root justfile's directory). The plan uses these symbols:

- `ROOT = justfile_directory()` — user's project root.
- `DEPS = $ROOT/just-plug.deps`
- `LOCK = $ROOT/just-plug.lock`
- `PLUGDIR = $ROOT/just-plug`
- `MODSFILE = $PLUGDIR/modules.just`

## Test infrastructure conventions

Integration tests use environment variable overrides to point fetch/resolve at local fixtures instead of github.com:

- `JUST_PLUG_GIT_BASE` — defaults to `https://github.com`. Tests set this to `file:///<tmp>/git`.
- `JUST_PLUG_RAW_BASE` — defaults to `https://raw.githubusercontent.com`. Tests set this to `http://127.0.0.1:<port>` after spinning up `python3 -m http.server`.

Both env vars are deliberately undocumented in the user-facing README — they exist only so tests can avoid the network.

# tests/lib/assert.sh — minimal assertion helpers. Source this from test scripts.

set -euo pipefail

# Track test results.
ASSERT_OK=0
ASSERT_FAIL=0

assert_eq() {
    local expected="$1"
    local actual="$2"
    local msg="${3:-}"
    if [ "$expected" = "$actual" ]; then
        ASSERT_OK=$((ASSERT_OK + 1))
    else
        ASSERT_FAIL=$((ASSERT_FAIL + 1))
        echo "FAIL: ${msg:-assert_eq}"
        echo "  expected: $expected"
        echo "  actual:   $actual"
    fi
}

assert_contains() {
    local haystack="$1"
    local needle="$2"
    local msg="${3:-}"
    if printf '%s' "$haystack" | grep -qF -- "$needle"; then
        ASSERT_OK=$((ASSERT_OK + 1))
    else
        ASSERT_FAIL=$((ASSERT_FAIL + 1))
        echo "FAIL: ${msg:-assert_contains}"
        echo "  haystack: $haystack"
        echo "  needle:   $needle"
    fi
}

assert_file_exists() {
    local path="$1"
    local msg="${2:-}"
    if [ -e "$path" ]; then
        ASSERT_OK=$((ASSERT_OK + 1))
    else
        ASSERT_FAIL=$((ASSERT_FAIL + 1))
        echo "FAIL: ${msg:-assert_file_exists}"
        echo "  missing path: $path"
    fi
}

assert_file_missing() {
    local path="$1"
    local msg="${2:-}"
    if [ ! -e "$path" ]; then
        ASSERT_OK=$((ASSERT_OK + 1))
    else
        ASSERT_FAIL=$((ASSERT_FAIL + 1))
        echo "FAIL: ${msg:-assert_file_missing}"
        echo "  unexpectedly present: $path"
    fi
}

assert_exit() {
    if [ "$ASSERT_FAIL" -gt 0 ]; then
        echo "$ASSERT_FAIL assertion(s) failed, $ASSERT_OK passed"
        exit 1
    fi
    echo "$ASSERT_OK assertion(s) passed"
}

Create `tests/lib/fixture.sh`:

```bash
# tests/lib/fixture.sh — spin up a local fixture: bare git repos + raw HTTP server.
#
# Usage:
#   . tests/lib/fixture.sh
#   fixture_setup "$TMPDIR"
#   fixture_add_module "<owner>/<repo>" "<entry-file>" "<tag>" "<content>"
#   # ... run plug commands against the fixture ...
#   fixture_teardown
#
# After fixture_setup, JUST_PLUG_GIT_BASE and JUST_PLUG_RAW_BASE point at the fixture.

# Internal state.
_FIXTURE_ROOT=""
_FIXTURE_GIT_ROOT=""
_FIXTURE_RAW_ROOT=""
_FIXTURE_HTTP_PID=""

fixture_setup() {
    local base="$1"
    _FIXTURE_ROOT="$base"
    _FIXTURE_GIT_ROOT="$base/git"
    _FIXTURE_RAW_ROOT="$base/raw"
    mkdir -p "$_FIXTURE_GIT_ROOT" "$_FIXTURE_RAW_ROOT"

    # Start a tiny HTTP server serving _FIXTURE_RAW_ROOT.
    cd "$_FIXTURE_RAW_ROOT"
    python3 -m http.server 0 >"$base/http.log" 2>&1 &
    _FIXTURE_HTTP_PID=$!
    cd - >/dev/null

    # Wait for the server to print its port.
    local port=""
    for _ in $(seq 1 50); do
        port="$(grep -oE 'port [0-9]+' "$base/http.log" 2>/dev/null | head -1 | awk '{print $2}' || true)"
        if [ -n "$port" ]; then break; fi
        sleep 0.05
    done
    if [ -z "$port" ]; then
        echo "fixture_setup: HTTP server did not start; log:" >&2
        cat "$base/http.log" >&2
        return 1
    fi

    export JUST_PLUG_GIT_BASE="file://$_FIXTURE_GIT_ROOT"
    export JUST_PLUG_RAW_BASE="http://127.0.0.1:$port"
}

# fixture_add_module <owner/repo> <entry-file> <ref> <content>
#
# Creates a bare repo at $_FIXTURE_GIT_ROOT/<owner>/<repo> with one commit
# containing <entry-file>, tags it as <ref>, and mirrors the file content to
# $_FIXTURE_RAW_ROOT/<owner>/<repo>/<sha>/<entry-file> so the HTTP server
# can serve it at the same path raw.githubusercontent.com would.
fixture_add_module() {
    local repo="$1" file="$2" ref="$3" content="$4"
    local work="$_FIXTURE_ROOT/work/$repo"
    local bare="$_FIXTURE_GIT_ROOT/$repo"

    mkdir -p "$(dirname "$work")" "$(dirname "$bare")"
    rm -rf "$work" "$bare"
    mkdir -p "$work"

    (
        cd "$work"
        git init -q -b main
        printf '%s' "$content" > "$file"
        git add "$file"
        git -c user.email=t@t -c user.name=t commit -q -m "add $file"
        git tag "$ref"
        git clone -q --bare . "$bare"
    )

    # Mirror file content for HTTP fetch keyed by the resolved SHA.
    local sha
    sha="$(git -C "$bare" rev-parse "$ref")"
    mkdir -p "$_FIXTURE_RAW_ROOT/$repo/$sha"
    printf '%s' "$content" > "$_FIXTURE_RAW_ROOT/$repo/$sha/$file"

    # Also mirror under the branch name (main) so default-ref tests work.
    local main_sha
    main_sha="$(git -C "$bare" rev-parse main)"
    mkdir -p "$_FIXTURE_RAW_ROOT/$repo/$main_sha"
    printf '%s' "$content" > "$_FIXTURE_RAW_ROOT/$repo/$main_sha/$file"
}

fixture_teardown() {
    if [ -n "$_FIXTURE_HTTP_PID" ]; then
        kill "$_FIXTURE_HTTP_PID" 2>/dev/null || true
        wait "$_FIXTURE_HTTP_PID" 2>/dev/null || true
        _FIXTURE_HTTP_PID=""
    fi
    unset JUST_PLUG_GIT_BASE JUST_PLUG_RAW_BASE
}
```

```just
# Parse a source identifier of the form github.com/<owner>/<repo>[@<ref>].
# Outputs three space-separated fields on stdout: <name> <source> <ref>.
# Exits non-zero on invalid input.
_parse-source spec:
    #!/usr/bin/env bash
    set -euo pipefail
    spec='{{spec}}'

    # Split off ref.
    if [[ "$spec" == *"@"* ]]; then
        ref="${spec##*@}"
        source="${spec%@*}"
    else
        ref="main"
        source="$spec"
    fi

    # Validate: must be github.com/<owner>/<repo> with no extra path components.
    if [[ ! "$source" =~ ^github\.com/[A-Za-z0-9._-]+/[A-Za-z0-9._-]+$ ]]; then
        echo "error: source must look like 'github.com/<owner>/<repo>', got: $source" >&2
        exit 1
    fi

    # Derive name: repo basename minus leading 'just-'.
    repo="${source##*/}"
    name="${repo#just-}"

    if [ -z "$name" ]; then
        echo "error: derived module name is empty for source $source" >&2
        exit 1
    fi

    echo "$name $source $ref"
```

# Resolve a ref to a 40-char commit SHA.
# Args: <source> <ref>
# - If <ref> matches ^[0-9a-f]{7,40}$, pass through unchanged.
# - Otherwise, git ls-remote against $JUST_PLUG_GIT_BASE/<source>.
_resolve-ref source ref:
    #!/usr/bin/env bash
    set -euo pipefail
    source='{{source}}'
    ref='{{ref}}'

    if [[ "$ref" =~ ^[0-9a-f]{7,40}$ ]]; then
        echo "$ref"
        exit 0
    fi

    base="${JUST_PLUG_GIT_BASE:-https://github.com}"
    url="$base/$source"

    # Try tag first, then branch. ls-remote prints lines like "<sha>\t<full-ref>".
    sha="$(git ls-remote "$url" "refs/tags/$ref" 2>/dev/null | awk 'NR==1{print $1}')"
    if [ -z "$sha" ]; then
        sha="$(git ls-remote "$url" "refs/heads/$ref" 2>/dev/null | awk 'NR==1{print $1}')"
    fi

    if [ -z "$sha" ]; then
        echo "error: could not resolve ref '$ref' in $source" >&2
        exit 1
    fi

    echo "$sha"
```

# Fetch <filename> at <sha> from <source> to <dest>.
# Writes via tempfile + atomic mv; on failure, <dest> is untouched.
# Outputs the sha256 of the fetched content on success.
_fetch source sha filename dest:
    #!/usr/bin/env bash
    set -euo pipefail

    #!/usr/bin/env bash
    set -euo pipefail
    root='{{justfile_directory()}}'
    spec='{{spec}}'

    if [ -z "$spec" ]; then

        # 1. For every dep, install at lock SHA if present, else freshly resolve.
        # 2. Remove any installed module not in deps.
        deps_names="$(just plug _read-deps | awk '{print $1}' | sort -u)"
        lock_names="$(just plug _read-lock | awk '{print $1}' | sort -u)"

        # Install / refresh every dep entry.
        while read -r name source ref; do
            [ -z "$name" ] && continue
            locked_line="$(just plug _read-lock | awk -v n="$name" -v s="$source" -v r="$ref" '$1==n && $2==s && $3==r {print}')"
            if [ -n "$locked_line" ]; then

                hash_recorded="$(echo "$locked_line" | awk '{print $5}')"

                : # leave it

        done < <(just plug _read-deps)

        for name in $lock_names; do

                rm -f "$root/just-plug/$name.just"
                just plug _remove-lock "$name"
            fi

        exit 0

    read -r name source ref < <(just plug _parse-source "$spec")

    if [ -f "$root/just-plug.lock" ]; then

            update_one "$n" "$src" "$ref"
        done < <(just plug _read-deps)

# Report modules whose pinned ref has moved upstream. Read-only.
outdated:
    #!/usr/bin/env bash
    set -euo pipefail
    found=0
    base="${JUST_PLUG_GIT_BASE:-https://github.com}"
    while read -r name source ref locked_sha hash; do
        [ -z "$name" ] && continue
        # SHA pin: never outdated.
        if [[ "$ref" =~ ^[0-9a-f]{7,40}$ ]]; then
            continue
        fi
        url="$base/$source"
        # Try tag.
        sha="$(git ls-remote "$url" "refs/tags/$ref" 2>/dev/null | awk 'NR==1{print $1}')"
        if [ -n "$sha" ]; then
            # Tag pin: look for newer tags by version-sort.
            newest="$(git ls-remote --tags "$url" 2>/dev/null \
                | awk '{print $2}' \
                | sed 's|refs/tags/||' \
                | grep -v '\^{}' \
                | sort -V \
                | tail -1)"
            if [ -n "$newest" ] && [ "$newest" != "$ref" ]; then
                # Only report if newest sorts strictly after ref.
                latest_sorted="$(printf '%s\n%s\n' "$ref" "$newest" | sort -V | tail -1)"
                if [ "$latest_sorted" = "$newest" ] && [ "$newest" != "$ref" ]; then
                    echo "$name: $ref → $newest (newer tag available)"
                    found=1
                fi
            fi
            continue
        fi
        # Branch pin.
        sha="$(git ls-remote "$url" "refs/heads/$ref" 2>/dev/null | awk 'NR==1{print $1}')"
        if [ -n "$sha" ] && [ "$sha" != "$locked_sha" ]; then
            echo "$name: $ref @ ${locked_sha:0:10} → ${sha:0:10} (branch moved)"
            found=1
        fi
    done < <(just plug _read-lock)
    if [ "$found" -eq 0 ]; then
        echo "all modules up to date"
    fi
```

A package manager for [just](https://just.systems) modules. Install third-party justfile modules from GitHub, pinned to a specific version, recorded in a manifest and lockfile.

just plug verify

just plug outdated

just plug install

## Module naming

The local module name is derived from the repo basename, with a leading `just-` stripped:

| Source | Module name | Local file |
|---|---|---|
| `github.com/foo/just-docker` | `docker` | `just-plug/docker.just` |
| `github.com/foo/docker` | `docker` | `just-plug/docker.just` |

To publish a module: drop a single `.just` file named `<module-name>.just` at the root of a public GitHub repo. Conventionally, name the repo `just-<module-name>`.

├── just-plug.deps             # manifest (what you want)

└── just-plug/
    ├── plug.just              # just-plug itself
    ├── modules.just           # auto-generated mod? lines
    ├── docker.just            # an installed module
    └── ...
```

## Limitations (v1)

- GitHub-only. No GitLab/Codeberg/raw URLs.
- One module per repo.
- No transitive dependencies.
- No semver ranges — pin to a tag, branch, or SHA.
- `outdated` for tag pins uses `sort -V` and may misbehave on unusual tag formats.
- Repos whose default branch isn't `main` require an explicit `@master` (or whatever) ref.
